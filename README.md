# Five Nights at Jairo's

Baseado nos relatos de meu querido amigo sobre seu local de trabalho.

Você é Jairo, o impressor da Gráfica do Jairo. Sobreviva aos turnos da noite fazendo os pedidos e encarando os "amigos" que se aproximam das portas.

**Jogar:** https://horizes.github.io/five-nights-at-jairo/

## Controles
- Arrastar o mouse / ← → — girar a sala 360°
- E — segurar para trabalhar / encarar
- S / L — luzes das portas da frente / dos fundos
- C — câmeras · Esc — pausar · M — mudo

Web audio e canvas puros — sem build, sem dependências.
